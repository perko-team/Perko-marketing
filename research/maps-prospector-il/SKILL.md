# Maps Prospector (ישראל)

סקריפט שמחפש ב-Google Maps סוג עסק באזור מסוים, אוסף את הפרטים שהעסקים פרסמו בעצמם ושומר CSV שנפתח נכון ב-Excel.

## שלב 0: אישור ופרמטרים (תמיד)

1. להסביר למשתמש: ״אני אפעיל דפדפן אוטומטי ברקע שמחפש ב-Google Maps ואוסף פרטים ציבוריים של עסקים.
   שימוש אוטומטי ב-Google Maps מנוגד לתנאי השימוש של Google ועלול לגרום לחסימה זמנית. להמשיך?״
2. לחכות לאישור מפורש. בלי אישור לא ממשיכים.
3. לשאול:
   - **סוג העסק** (למשל: בתי קפה, מאפיות, מספרות, חנויות פרחים)
   - **עיר או שכונה** (למשל: ירושלים, נחלאות, רמת גן)
   - **מייל מהאתר?** (איטי יותר; כן או לא)
   - **השם שיופיע בהודעה** (למשל: דנה)
4. לחזור על הפרמטרים ולקבל אישור.

## שלב 1: הכנה והרצה

```bash
pip install playwright
python -m playwright install chromium
```

```bash
python scripts/scrape_maps.py --sector "[סוג העסק]" --zona "[עיר]" --sender "[שם]" --output "לידים_[סוג]_[עיר].csv"
```

תוספות: `--enrich-email` לחיפוש מייל באתר העסק, `--max-results 30` להרצה קצרה, `--show-browser` כדי לראות את הדפדפן.

## מה הסקריפט עושה

1. מחפש ״[סוג העסק] ב[עיר]״ ב-Google Maps בעברית (`hl=iw`, `gl=il`, אזור זמן ירושלים).
2. גולל את רשימת התוצאות (עד כ-60, המגבלה של Maps).
3. פותח כל עסק ואוסף: שם, קטגוריה, טלפונים, כתובת, אזור, אתר, דירוג, ביקורות וקישור לעסק במפות.
4. מסווג טלפונים ישראליים: **נייד** 05X, **נייח** 02/03/04/08/09, **אחר** 07X (VoIP), 1-700/1-800 וכוכבית.
5. מדלג על עסקים בלי טלפון ועל כפילויות (אותו שם ואותה כתובת).
6. ממיין לפי שלמות הפרטים ושומר CSV ב-UTF-8 עם BOM.
7. בוחר **2 לידים אידיאליים** (`--leads` לשינוי): עסק עצמאי (לא רשת), מסוג שחוזרים אליו (קפה, מאפייה, מספרה,
   גלידה, פיצה, חומוס, פרחים ועוד), דירוג 4.2 ומעלה, 40-1500 ביקורות, ושיש לו **נייד או מייל**.
8. מדלג על עסקים שכבר הוצעו בהרצות קודמות (`leads_history.json` ליד ה-CSV), כך שכל הרצה מביאה לידים חדשים.
9. כותב `leads_<תאריך>.md` עם הפרטים של כל ליד, למה הוא מתאים, והודעה מוכנה: וואטסאפ/SMS ופתיח לשיחה
   (כשיש נייד) ומייל (כשיש מייל). ההטבה בהודעה מותאמת לסוג העסק, למשל ״קפה עשירי עליכם״.

עמודות: `שם, קטגוריה, נייד, נייח, טלפון אחר, מייל, אתר, ביקורות, דירוג, אזור, כתובת, קישור במפות`

## כללים

- **לא להמציא נתונים.** שדה שלא נמצא נשאר ריק.
- **לבדוק לפני שימוש.** כל שורה כוללת קישור במפות כדי לוודא אותה ידנית. פרטים ב-Maps מתיישנים.
- **חוק הספאם (חוק התקשורת, סעיף 30א):** אסור לשלוח לרשימה הזו פרסום במייל, SMS, וואטסאפ או חיוג אוטומטי
  בלי הסכמה מראש. החוק מתיר לפנות לבית עסק **פעם אחת** בבקשה לקבל הסכמה, ולכן ההודעות המוכנות כתובות כהיכרות
  ובקשה לעשר דקות, עם אפשרות לבקש לא לפנות שוב. לשלוח אותן ידנית, אחת אחת, לא בתפוצה. מי שלא עונה או מסרב, לא פונים אליו שוב.
  שיחה אישית או ביקור בעסק תמיד בטוחים יותר.
- **פרטיות:** נייד שמופיע בעסק יכול להיות מספר אישי של הבעלים. לשמור את הקובץ במקום מוגבל ולא לשתף אותו.
- **קצב:** הסקריפט ממתין בין פעולות. לא להריץ הרבה חיפושים ברצף; Google חוסם גישה אוטומטית.

## הצגת התוצאה

1. להציג בצ׳אט את **2 הלידים** עם ההודעות המוכנות מתוך `leads_<תאריך>.md`.
2. למסור את קובץ ה-CSV המלא ואת קובץ הלידים.
3. לסכם במשפט: כמה עסקים נמצאו, כמה עם נייד, נייח, אתר ומייל.
4. להזכיר במשפט: הודעה ראשונה אחת בלבד, שמבקשת הסכמה; מי שלא מעוניין לא מקבל פנייה נוספת.
5. אם לא נמצאו לידים חדשים עם נייד או מייל: להציע אזור או סוג עסק אחר, או הרצה עם `--enrich-email`.

## אם משהו לא עובד

- **״לא נמצאה רשימת תוצאות״:** Google שינו את מבנה הדף, או שהחיפוש החזיר עסק בודד. לנסות ניסוח רחב יותר.
- **אין טלפונים בכלל:** הסלקטורים ב-Maps השתנו. להריץ עם `--show-browser` ולבדוק את מבנה הדף.
- **חסימה או CAPTCHA:** לעצור ולחכות כמה שעות.
